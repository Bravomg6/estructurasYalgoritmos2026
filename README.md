# estructurasYalgoritmos2026

Trabajo práctico de la materia Estructuras de Datos y Algoritmos (segundo año, Ingeniería Informática).

## Cómo se hicieron los ejercicios

Por cada ejercicio armé un prompt con lo que pide la consigna y se lo pasé a OpenCode para que me genere el código en Java. El mismo prompt quedó pegado como comentario arriba de cada archivo, así está junto a la consigna y se puede ver de dónde salió el código.

## Qué hay en este repo

- `practico01` — Intro a Java (12 ejercicios)
- `practico04` — Análisis de algoritmos
- `practico05` — Recursividad
- `practico06` — Ordenamiento
- `practico07` — Pilas y colas con arreglos
- `practico08` — Listas enlazadas simples
- `practico09` — Pilas y colas con listas enlazadas

El práctico 03 era sobre Git y GitHub y no tenía ejercicios de Java, por eso no tiene carpeta.

También están los `.docx` con las consignas de cada práctico.

## Cómo está organizado cada archivo

Cada `.java` tiene dos comentarios al principio:

1. **Prompt inicial utilizado** — el texto exacto que le pasé a OpenCode.
2. **Ajustes realizados** — los cambios que se le hicieron a mano después, si hizo falta.

Todos los archivos compilan con `javac` sin errores.
